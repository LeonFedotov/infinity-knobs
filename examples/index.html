infinity-knobs

Precise, endless MIDI knobs in the browser.

Drag the knob up or down, scroll over it, or hold an arrow key (Shift spins it). Turned slowly, each value moves a quarter of a cent; spun fast, 50 cents. Near either end it is sent back to 64, so it never runs out.
